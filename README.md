# AgroBoost - Agricultural Management System

AgroBoost is a web-based agricultural management system designed to connect farmers and agricultural sellers in a simple and efficient way. It allows users to browse agricultural products, view details, and communicate with sellers to improve agricultural trade and accessibility.

## Features

- Farmer module to browse and search agricultural products  
- Product listing with availability and details  
- Direct communication between farmers and sellers  
- Order inquiry and management system  
- Seller dashboard to manage product listings  
- Easy product search and filtering  
- Basic system structure for agricultural data handling  

## Tech Stack

- Frontend: HTML, CSS, Bootstrap, JavaScript  
- Backend: PHP  
- Database: MySQL  
- Server: Apache (XAMPP/WAMP)  

## Project Structure

AgroBoost/
│── assets/         # CSS, JS, images  
│── config/         # Database configuration  
│── includes/       # Reusable PHP components  
│── pages/          # Main application pages  
│── admin/          # Admin panel  
│── database.sql    # Database file  
│── index.php       # Entry point  

## Installation Guide

1. Clone the repository  
   git clone https://github.com/mdnaseeransari/agroboost.git  

2. Move the project to htdocs (if using XAMPP)  

3. Start Apache and MySQL using XAMPP  

4. Import the database  
   - Open phpMyAdmin  
   - Create a database (example: agroboost)  
   - Import database.sql file  

5. Run the project in browser  
   http://localhost/agroboost
